# ProofChain AI

AI-powered scam, phishing & trust verification platform.

## Features
- Scam screenshot detection
- OCR text extraction
- AI risk scoring
- URL phishing scanner
- Trust dashboard

---

# Backend Setup

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

---

# Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
